# Sample training data (5 rows each)

Small samples of the datasets used to train the three ML models. Full data is
generated by `backend/app/ml/training/generate_dataset.py` (reproducible, seed 42).

| File | Module | Source table | Label / target |
| --- | --- | --- | --- |
| `1_demand_forecasting_sample.csv` | Demand Forecasting | `demand_summary.csv` | `bookings` (weekly demand) |
| `2_anomaly_detection_sample.csv` | Anomaly Detection | `telemetry_daily.csv` (behaviour) | `is_anomaly` / `anomaly_type` |
| `3_predictive_maintenance_sample.csv` | Predictive Maintenance | `telemetry_daily.csv` (sensors) | `maintenance_within_30d` |
| `4_equipment_master_sample.csv` | shared reference | `machines.csv` | — (joined into demand + maintenance) |

**Note:** Anomaly and Maintenance both read the same daily telemetry feed —
Anomaly looks at *behaviour* (operator, fuel, idle, GPS), Maintenance looks at
*sensor wear* (engine hours, temps, vibration). `machines.csv` is the fleet
catalogue joined into both.
